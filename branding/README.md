# 3re brand kit

**The mark: three views, dissolving into pixels.** The isometric cube's Front, Side and Top faces are drawn apart
and read as one solid, the three views 3re builds a model from. The Front face's top-left corner steps down like a
pixel stair and three pixel squares break away from it: a picture or a pixel drawing becoming 3D. There is no
background tile; the symbol is the icon. Tones and even seams carry the shape, so it stays a cube at 16 px and in
one colour.

Everything here is generated by one construction (`python tools/make_3re_icon.py`): cube edge 132, seam 18.5,
corner radius 13.9, a 3 x 3 pixel grid on the Front face (pixel seam 6, pixel corners 2) on a 256 grid. Change a
number there, rebuild, and every file follows.

## Files

| Folder / file | What it is |
|---|---|
| `svg/3re-symbol.svg` | Master symbol, colour, for dark surfaces |
| `svg/3re-symbol-light.svg` | Same ramp, deepened, for white and light-grey surfaces |
| `svg/3re-symbol-black.svg`, `-white.svg` | One colour. The white one has wider seams (white on dark looks heavier) |
| `svg/3re-symbol-brand.svg` | One colour in brand slate `#4F6593` |
| `svg/3re-symbol-small.svg`, `-small-light.svg` | Small-size cut: wider seams and a single pixel square, for 16-32 px |
| `svg/3re-app-icon.svg` | App icon: the light-surface symbol, transparent (holds on dark and light taskbars) |
| `svg/3re-app-icon-small.svg` | App icon for 16-32 px (small-size cut) |
| `svg/3re-lockup-{horizontal,stacked}-{dark,light}.svg` | Symbol + wordmark, outlined (no live text) |
| `png/` | Renders for documents and the web, `favicon.ico` (16/32/48, small cut) |

In the application (`apps/gui/resources/`): `3re.ico` (16-32 px = small cut), `3re.png` (window icon),
`3re-512.png` (splash), `3re-mark.png` (dark-surface symbol, 128 px: Home page, About, pixel start screen).

| Left face (UI accent) | `#7C93C4` | 124, 147, 196 | 37, 25, 0, 23 |
| Right face (brand slate) | `#4F6593` | 79, 101, 147 | 46, 31, 0, 42 |
| Top face, on light | `#9CAFDB` | 156, 175, 219 | 29, 20, 0, 14 |
| Left face, on light | `#6E87BD` | 110, 135, 189 | 42, 29, 0, 26 |
| Wordmark on dark / light | `#E4E7EC` / `#1B1E24` | | |

The faces are the application's own slate-blue ramp (`apps/gui/theme.cpp`: accent hover, accent pressed).
CMYK values are device-independent estimates; proof before printing. No Pantone match is claimed.

Contrast against the surface (WCAG ratio): dark ramp on `#14161B` is 10.7 / 5.9 / 3.1 (top / left / right);
light ramp on white is 2.2 / 3.6 / 5.8. The top face is lit by design; the seams, not its contrast, separate it.

## Use

- **Clear space:** 3 x the width of the seam between the left and right faces (about a quarter of the
  symbol's height) on every side.
- **Minimum size:** symbol 16 px (use the small cut, or the app icon small cut) or 8 mm; lockup 24 px symbol
  height or 25 mm wide.
- **Surfaces:** charcoal and dark photos take the colour symbol; white and light grey take the light symbol;
  brand slate `#4F6593` and mid-tones take the white symbol; print in one colour takes black.
- **Wordmark:** Lato Semibold, outlined. Lato is licensed under the SIL Open Font License 1.1, which allows
  this use. Do not retype it; use the lockup files. The in-app label "3re" is interface text, not the logo.
- **Do not:** add a background tile to the app icon, recolour single faces, close the seams, add outlines, shadows or glows to the symbol, rotate,
  skew or stretch it, or put the colour symbol on a surface where the right face drops below 3:1.

## Rebuild

```
python tools/make_3re_icon.py            # SVG masters, PNG/ICO, resources for the app
python tools/make_3re_icon.py --no-raster # SVG only (no cairosvg needed)
```

Needs Python 3, `cairosvg` (rasters) and `fontTools` plus the Lato Semibold font (`--font PATH`, default
`C:\Windows\Fonts\LatoWeb-Semibold.ttf`) for the lockups. After a rebuild, rebuild the application: the PNG and
ICO files are compiled into `3re.exe`.

## Limits

Trademark clearance was not searched: have a professional check trademark databases and run a reverse image
search before using the mark outside this project. Study of reference marks never copied any of them.
